# Slogan and voice

**Slogan**  
Give shape to an idea.

**One-line descriptor**  
A local toolkit for inspecting, creating, converting, and repairing 3D assets.

**Proposed README opener**  
Blender-Agent Refinement Toolkit is a pre-alpha Python toolkit for working with 3D assets locally. Use its CLI or connect BART to an MCP host.

**UI and documentation voice**  
Lead with the task, name the input or output, and state the next action. Use short, concrete sentences.

| Scenario | Copy proposal |
| --- | --- |
| First example | Inspect a triangle OBJ and check its vertex count, face count, and bounds. |
| Output path already exists | Choose a new output filename to keep the existing file. |
| Missing Blender executable | Set the Blender executable path to run this operation. |

Use the slogan where space permits a title, descriptor, and short supporting line. Keep it in editable text so it can wrap and be read by assistive technology.
