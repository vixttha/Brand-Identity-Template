# PNG exports

Use @Images for every brand image created through this kit. Save project PNGs here and add each to [manifest.json](manifest.json) with its role, alt text, native width and height, alpha-channel policy, SHA-256, and generation provenance. Save the subject, requested text, palette, avoid list, source references if any, and material edits with the asset. Include only project-appropriate references.

Use filenames with a stable role and revision. Record the review state and any usage conditions before distributing the imagery. Images shared solely as evidence or references can remain linked from the brief.
