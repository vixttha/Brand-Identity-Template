# Logo review standards

Use this checklist after the initial creative review and before adopting a mark. Record the intended surfaces, version reviewed, outcome and evidence for each check. Choose test sizes for the surfaces the project actually uses.

| Check | Evidence to record |
| --- | --- |
| 1. Distinctive silhouette | Compare the mark in one color beside relevant products and tools. Note whether the shape can be identified without the wordmark. |
| 2. Three meanings in visible details | Tie each meaning to a visible contour, cut, junction or letter feature. Record what a viewer notices first and which reading each detail adds. |
| 3. Small-size legibility | Render at the intended favicon and avatar sizes. Check the identifying detail and test the circular crop used by the intended platform. Document the minimum verified size and any compact variant. |
| 4. One color and dark mode | Review solid dark and light versions on their intended surfaces. Retain the key silhouette and internal space in both. |
| 5. Logo system | Define the symbol, wordmark and fixed combined layout. Document which variant goes on which surface and where the full product name needs to appear. |
| 6. Clear space and consistency | Define a measurable margin, spacing between symbol and type, approved backgrounds, and placement examples. Use the same files in representative layouts. |
| 7. Readability and accessibility | Test wordmark spelling at the intended size with a reader unfamiliar with the project. A logo used as the sole content of a home link must give the link an accessible name that indicates where it leads. |
| 8. Production files | For an approved identity, retain an editable master and export SVG, transparent PNG, and favicon assets as the deployment surfaces require. Record versions, generation provenance where applicable, usage notes and reuse terms. |
| 9. Similarity review | Compare names and designs used by related products before public adoption. Record the scope and results of a preliminary review. Follow the relevant clearance process for the intended market. |

Compare finalist silhouettes on the same background and at the same size. Give the viewer no legend on the first pass. If the detail carrying the main meaning disappears, simplify that detail before refining palette and lettering. A written concept has pending rendering checks until artwork is reviewed.

## Reference practices

- [IBM 8-bar logo guidance](https://www.ibm.com/design/language/ibm-logos/8-bar/) documents clear space and logo use.
- [GOV.UK logo system](https://brand.design-system.service.gov.uk/logo-system/) and [brand hierarchy](https://brand.design-system.service.gov.uk/logo-system/brand-hierarchy/) show how to specify variants, fixed combined layouts, and spacing.
- [W3C functional images guidance](https://www.w3.org/WAI/tutorials/images/functional/) gives examples of accessible names for image-only home links.
- [USPTO clearance guidance](https://www.uspto.gov/trademarks/search/comprehensive-clearance-search-similar-trademarks) describes US searches for potentially confusing marks.
