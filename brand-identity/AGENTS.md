# Brand identity work

Use this workflow when the owner asks for brand identity work. Read the target repository's applicable instructions and the [kit README](README.md). Identify the target project from the owner or the checkout. Use accessible source, approved copy, and owner answers as brand evidence.

1. Read the [brief](01-strategy/brief.md) and ask for any missing facts that would change the design. Find out what the project changes for people, what it deliberately preserves, and where the identity will first appear.
2. Produce four separately labeled shortlists: project names, logos, slogans, and wordmarks. Apply the [meaning method](01-strategy/meaning-method.md) to every option. Screen logo categories, specify the art style, and score the logo options using the [creative direction workflow](01-strategy/creative-direction.md).
3. Present the four lists with the trade-offs and a suggested pairing. Record the options in the [creative decision](01-strategy/creative-decision.json). Ask the owner to confirm exact product and wordmark text before drawing. Retain existing authorized names when the owner keeps the naming decision closed.
4. After the owner confirms the exact strings, verify artwork readiness and use @Images for production PNGs. Inspect the work in one color and at the intended display size. Preserve the source and the owner decision.

For a repository-hosted agent without automatic instruction discovery, explicitly point it to this file for the brand identity task.
