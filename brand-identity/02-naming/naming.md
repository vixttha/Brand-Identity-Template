# Naming

| Role | Exact form | Usage |
| --- | --- | --- |
| Product | Blender-Agent Refinement Toolkit | First mention, project title, repository description |
| Agent | BART | Logo lettering, shorthand after introducing the toolkit, agent references |
| Historic project name | Blender-Agent | Period-specific notes and archived material |
| Compatibility identifiers | `blender-agent`, `blender-agent-mcp`, `blender_agent`, `BLENDER_AGENT_*` | Commands, Python imports, and environment settings |

The name decision comes from [issue #62](https://github.com/vixttha/Blender-Agent-Refinement-Toolkit/issues/62). The simple reading “Bart” is a proposed spoken form. Use the full project name on first mention, particularly when search or context could make the short name ambiguous.

The short name shares a spelling with Bart Simpson when case is ignored. The visual direction avoids character imagery, signature hair, and other franchise cues. Name and mark clearance remain open. Record any relevant search results and decisions here before wider use.
