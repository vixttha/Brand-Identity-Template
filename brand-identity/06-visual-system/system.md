# Visual system

| Token | Hex | Role |
| --- | --- | --- |
| Ink | `#17252D` | Logo foundations, wordmark, light-surface text, dark canvas |
| Mist | `#F4F6F2` | Light canvas, light label color on ink, backing for draft PNGs |
| Mint | `#38E6A8` | Facet and accent cues on ink |

These are proposed UI tokens. The generated draft artwork has minor local color variation. Ink and Mist have 14.42:1 contrast. Mint and Ink have 9.75:1. Mint and Mist have 1.48:1, so light-surface labels and essential indicators use Ink.

**Typography proposal.** Use Geist for headings and body with system sans-serif fallback, and a system monospace stack for technical examples. Treat the raster lettering as a wordmark asset. Use live text for the product name and reading content.

**Layout.** Lead with one heading and a direct product descriptor. Pair the mark with space around it. Use the diagonal geometry selectively in illustrations and preserve the reading grid.

**Imagery.** Use neutral geometry grounded in documented operations. Favor inspectable forms, clear silhouettes, and a single color accent. Prefer actual captured output for evidence. Label generated illustrations by purpose.
