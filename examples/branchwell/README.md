Selected direction: overlapping B/W circles. Dark evergreen #154e3b, deep green #102c21, porcelain #f1f4f1, and white #ffffff. Instrument Sans where available, with Segoe UI fallback. Use the lockup in navigation, the initials at compact sizes, and a quarter-circle diameter of clear space.

The voice uses exact verbs, factual activity comparisons, and concrete next actions. Typical UI language includes “Sync GitHub”, “Save profile”, and “Open work mode.” Keep public imagery fictional and check text contrast, lettering, compact mark legibility, and light placement before registering PNG assets.
