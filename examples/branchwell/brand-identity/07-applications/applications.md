# Applications

| Surface | Application |
| --- | --- |
| Overview | Put the focus queue first and names, status, last push and next action in the directory. |
| Profile | Pair source metadata with the editable work profile. Preserve field labels and source dates. |
| Work mode | Present a ranked queue with one actionable sentence per repository. |
| Activity | Compare the two windows in their own view with actual labels and a table alternative. |
| Hosted Settings | Explain the GitHub data source, import controls and privacy boundary. |
| README | Pair the working name with a one-line descriptor, then show a concise usage path. |

Mobile keeps repository names and status prominent. Reserve other details for the profile and preserve an obvious way into Work mode.
