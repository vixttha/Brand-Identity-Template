# Visual system

| Role | Value |
| --- | --- |
| Paper | #faf9f6 |
| Main type | #20221f |
| Graphite navigation | #242622 |
| Menu type on graphite | #f4f1e9 |
| Secondary text | #585a53 |
| Table and panel rules | #d8d7cc |
| Oxide action accent | #9d4829 |
| Pale action background | #f2e2d8 |

Use Segoe UI or a system humanist sans. Body and working controls use a consistent 14–16px scale. Use a compact heading and reserve tabular figures for dates and counts. Border radius stays between 0 and 4px. Give the directory a single reading surface broken by rules. A visible outline treatment serves keyboard focus. Status always carries text.
