# Voice

Describe the next action and the evidence that supports it. Use “Open profile”, “Save profile”, “Open Work mode” and “Import from GitHub”. Distinguish a saved snapshot from a checked source.

| Context | Copy |
| --- | --- |

| Data date | GitHub data imported {date} |

Reserve the original phrase “Your repositories. Your next move.” for context such as a README. Keep it out of the signed-in navigation.
