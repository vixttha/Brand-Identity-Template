# Branchwell creative brief

Branchwell is a personal GitHub repository workbench. Its first audience is a maintainer switching between dozens of repos with uneven priorities. The first placement is the hosted workspace on a laptop. Its job is to help the maintainer resume work, inspect current GitHub facts, and decide what to do next.

The owner described the first dashboard as generic AI output. Use the visual language of a maintained directory. Favor readable rows, aligned controls, concise labels and one functional accent. Leave portfolio trends on the Activity page.

Source material consists of the product brief and fictional interface data. Reserve actual repository names and metrics for the signed-in workspace.
