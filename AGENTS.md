# Brand Identity Template project instructions

The repository contains a reusable workflow for naming, visual identity, and brand copy. For an owner-requested branding session, read the [kit operating instructions](brand-identity/AGENTS.md) and apply them to the target project's evidence. When maintaining this template, use synthetic or generic examples.

Validate kit changes with `python3 brand-identity/verify.py` and the public-runner workflow. Owner approval governs downstream adoption, merges, and releases.
