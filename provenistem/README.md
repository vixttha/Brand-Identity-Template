# Provenistem for Brand Identity Template

This is Brand Identity Template's project-owned ideas and features library. The JSON records follow the Provenistem v0.0.2 record format from Governance Branch. The Governance package is distributed privately. This public library contains project-authored records and public evidence.

- [Ideas](ideas/INDEX.md) records options and open questions.
- [Features](features/INDEX.md) records capabilities, implementation state, acceptance criteria, and verification receipts.
- [Brand Identity Template v0.0.2](https://github.com/vixttha/Brand-Identity-Template/releases/tag/v0.0.2) is the authority for the released kit. [Meaning-led identity](https://github.com/vixttha/Brand-Identity-Template/tree/99a897ab9dd927fa82c22ed3b20ac355d1f84d3a) is a separate working branch.

## Update the library

Use the next unused project-local ID when adding a record. Link a feature to the ideas it develops and update the relevant index. Keep evidence attached to the commit and source path it covers. Record test outcomes only after obtaining a run or audit receipt for that revision. Project decisions and released versions belong to their own records.

Browse and edit these files directly in GitHub. The library has no application or Governance runtime dependency. A maintainer with access to Provenistem can validate the records in a separate copy of its v0.0.2 package.
