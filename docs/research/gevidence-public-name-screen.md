# GEvidence public name screen

**Date.** November 19, 2026. The proposed product is a developer kit that links repository features to committed source, tests and verification receipts. The adopting project's name record is a first-party result. [GEvidence naming record](https://github.com/vixttha/Graphify-HQ/blob/27b072347231d25fd7a817ef362ece81acb1e839/brand-identity/02-naming/naming.md)

**Assessment.** GEvidence has a confirmed exact-name software overlap and a confirmed exact-match .com conflict. Its GitHub namesakes serve ESG verification, while the new kit serves software maintainers. They share the language of evidence and verification and could be confused in general searches. If a distinct searchable identity and the matching .com are priorities, reconsider the name before a public launch.
